# The Evolution of the Atom: From Dalton to the Modern Model

An interactive science-museum experience for 10th-grade New York State Regents Chemistry (NYSSLS HS-PS1-1). Students investigate the evidence behind each of the five atomic models and see why scientific models change.

**Time:** 45–60 minutes · **Format:** one self-contained `index.html`, no install or sign-in.

## Galleries (each unlocks the next)

1. **Dalton (early 1800s):** rotatable solid sphere; build H₂O, CO₂, NH₃, and CH₄ to discover fixed whole-number ratios.
2. **Thomson (1897 / 1904):** plum pudding model with clickable electrons; a working **cathode ray tube** with an electric field you can apply and reverse.
3. **Rutherford (1911):** predict the plum pudding result, then run the **gold foil experiment** in batches of 10, 50, or 100 with live tallies.
4. **Bohr (1913):** absorb and emit energy between levels n = 1–6 and build hydrogen's visible spectrum (656, 486, 434, 410 nm).
5. **Modern (1920s on):** measure electron positions in 1s and 2p orbitals and watch the probability cloud and distance histogram build up; Bohr vs. modern comparison; Chadwick neutron extension.

## Labs

- **Model Comparison Lab:** compare any two models across seven categories, then sort 10 statement cards.
- **Evidence Changes Everything!:** match six observations to models and conclusions, then explain what each one challenged.
- **Build the Timeline:** order the models, then replay how evidence drove each change.
- **Atomic Model Detective:** 18 cases using model images, experiment diagrams, discoveries, and limitations. A wrong answer gives a hint, not the answer.
- **Final Assessment:** 20 questions (8 multiple choice, 4 model identification, 4 experiment/evidence, 2 comparison, 2 CER written responses). Includes a score report, models mastered, concepts to practice, retry, and a copyable summary.

## Notes for teachers

- Particle colors: protons red, neutrons blue, electrons grey. Historical models show only the particles known at the time.
- Gold foil counts are labeled simulation data. Large-angle scattering is made more common than the real rate (about 1 in 8,000) so students can see it.
- Written responses get keyword-based rubric feedback and an exemplar; they are not auto-graded.
- Four learning levels adjust hints, sentence starters, and visual prompts. Includes reduced motion, keyboard controls, read-aloud, and a vocabulary panel.
- A "Teacher: unlock all galleries" button at the bottom skips the gating for demos.
- Progress is saved only in each student's own browser.

To use it, open `index.html`, or enable GitHub Pages for this repository.
